# Eksperimen SML - Galih Aji Pangestu

Repository Kriteria 1 submission kelas Membangun Sistem Machine Learning (Dicoding).

## Struktur

```
Eksperimen_SML_Galih-Aji-Pangestu/
├── diabetes_raw/
│   ├── diabetes.csv
│   └── diabetes_with_headers.csv
└── preprocessing/
    ├── Eksperimen_Galih-Aji-Pangestu.ipynb
    └── diabetes_preprocessing/
        ├── diabetes_clean.csv
        ├── train.csv
        └── test.csv
```

## Isi Notebook

Notebook `preprocessing/Eksperimen_Galih-Aji-Pangestu.ipynb` mencakup:
- Data loading
- Exploratory Data Analysis (EDA)
- Preprocessing data diabetes

## Cara Menjalankan

1. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn`
2. Buka dan jalankan seluruh cell di `preprocessing/Eksperimen_Galih-Aji-Pangestu.ipynb`
